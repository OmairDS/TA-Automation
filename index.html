المحور الثاني · Power Query

الخطوات نفسها بلغة M

لا تكتبها يدوياً، الواجهة تكتبها عنك. لكن قراءتها تجعلك تفهم ما يتكرر عند كل تحديث.

let
    Source   = Csv.Document(File.Contents("C:\Reports\TA.csv"), [Delimiter=",", Encoding=65001]),
    Headers  = Table.PromoteHeaders(Source, [PromoteAllScalars=true]),
    Types    = Table.TransformColumnTypes(Headers, {{"Date", Int64.Type}, {"Cost", type number}, {"Sale", type number}}),
    NoErr    = Table.ReplaceErrorValues(Types, {{"Cost", null}}),
    ToDate   = Table.TransformColumns(NoErr, {{"Date", each Date.From(_), type date}}),
    FixRep   = Table.ReplaceValue(ToDate, "Mjeeed", "Mjeed", Replacer.ReplaceValue, {"Rep"}),
    FixStore = Table.ReplaceValue(FixRep, "Lulu Hyper", "Lulu", Replacer.ReplaceValue, {"Store"}),
    Valid    = Table.SelectRows(FixStore, each [Cost] <> null and [Cost] < [Sale] and Date.Year([Date]) <= 2006),
    Profit   = Table.AddColumn(Valid, "Profit", each [Sale] - [Cost], type number)
in
    Profit

    ' 1) Refresh all queries and pivot tables
    ThisWorkbook.RefreshAll
    Application.CalculateUntilAsyncQueriesDone

    ' 2) Export the dashboard as a dated PDF
    Sheets("Dashboard").ExportAsFixedFormat _

End Sub

الأتمتة بـ Python

من البيانات إلى تقرير مجدول

المحور الثالث · pandas

الخط كاملاً في سكربت واحد

نفس المنطق الذي بنيناه في Power Query، سطراً مقابل خطوة.

import pandas as pd

df = pd.read_csv("TA.csv")
df["Date"] = pd.to_datetime(df["Date"], unit="D", origin="1899-12-30")   # Excel serial → date
df["Cost"] = pd.to_numeric(df["Cost"], errors="coerce")                    # blanks → NaN
df = df.replace({"Rep": {"Mjeeed": "Mjeed"}, "Store": {"Lulu Hyper": "Lulu"}})
df = df[(df["Cost"] < df["Sale"]) & (df["Date"].dt.year <= 2006)]
df["Profit"] = df["Sale"] - df["Cost"]

summary = df.pivot_table(index="City", values=["Sale", "Profit"], aggfunc="sum")

with pd.ExcelWriter(f"report_{pd.Timestamp.today():%Y-%m-%d}.xlsx") as xw:
    summary.to_excel(xw, sheet_name="Summary")
    df.to_excel(xw, sheet_name="Data", index=False)

المحور الرابع · مثال

من جدول الأرقام إلى ملخص تنفيذي

ما نرسله: الجدول المحسوب فقط، لا البيانات الخام
أنت محلل مبيعات. هذا ملخص المبيعات والربح حسب المدينة بعد التنظيف.
اكتب ملخصاً تنفيذياً بالعربية في 4 نقاط:
• أبرز مدينة في المبيعات وأبرزها في الربح
• ملاحظة عن هامش الربح
• مدينة تحتاج متابعة
• سؤال واحد تقترح أن تطرحه الإدارة
لا تحسب أرقاماً جديدة، استخدم الأرقام كما وردت فقط.
ما يعود به (يُراجَع قبل الإرسال)
  • تتصدّر الدمام المبيعات بـ 1.86 مليون، بينما تتصدّر الرياض الربح بـ 709 ألف.
  • هامش الرياض 39.6% مقابل 36.8% للدمام، أي أن ربحية البيع أعلى في الرياض.
  • حائل الأدنى مبيعاً وربحاً، وتحتاج متابعة على مستوى المندوبين والسلاسل.
  • سؤال للإدارة: ما الذي يرفع هامش الرياض، وهل يمكن نقله إلى الدمام؟

المحور الرابع · داخل السكربت

الملخص يُكتب تلقائياً مع كل تشغيل

نضيف بضعة أسطر إلى نهاية السكربت نفسه، فيصبح الملخص جزءاً من الخط المجدول.

import anthropic

client = anthropic.Anthropic()          # reads ANTHROPIC_API_KEY from env

prompt = ("Write a 4-point executive summary in Arabic for this table. "
          "Do not compute new numbers:\n" + summary.round(0).to_string())

msg = client.messages.create(
    model="claude-sonnet-5-5", max_tokens=600,
    messages=[{"role": "user", "content": prompt}],
)
pd.DataFrame({"Summary": [msg.content[0].text]}).to_excel("summary.xlsx", index=False)
لاحظ: نرسل جدول summary المكوّن من 6 صفوف، لا الـ 1,991 صفاً.
